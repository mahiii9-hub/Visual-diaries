# Graphic Designing Diaries 🎨✨

Welcome to my creative visual space! This repository is dedicated to storing and organizing all my graphic design assets, brand identities, and creative works crafted using Canva.

## 📂 What's Inside This Repository?

* **Brand Logos & Identity:** Custom-designed logos and typography for branding projects (e.g., SAVORA brand identity).
* **Promotional Banners & Posters:** Eye-catching digital banners, sale ads, and event flyers designed for web and social media.
* **UI Elements & Graphic Cards:** Custom cards, visual layouts, and graphics created to enhance web design projects.

## 🛠️ Tools & Technologies Used
* **Primary Tool:** Canva
* **Asset Formats:** High-resolution PNGs and graphics
* **Usage:** Integrated directly into frontend web development projects via raw links.
